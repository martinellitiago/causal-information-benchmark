References and provenance
=========================

* Martinelli, Soares-Pinto and Rodrigues. *Shaking the causal tree: On the
  faithfulness and minimality assumptions beyond pairwise interactions*.
  `arXiv:2203.10665v3 <https://arxiv.org/abs/2203.10665v3>`_.
* Peixoto (2019). *Network Reconstruction and Community Detection from Dynamics*.
  `PRL 123, 128301 <https://doi.org/10.1103/PhysRevLett.123.128301>`_.
  Context for kinetic and epidemic model families.
* Iacopini, Petri, Barrat and Latora (2019). *Simplicial models of social contagion*.
  `Nature Communications <https://doi.org/10.1038/s41467-019-10431-6>`_.
  Context for group infection, with different update and noise conventions here.
* Kauffman (1969). *Metabolic stability and epigenesis in randomly constructed
  genetic nets*. `Journal of Theoretical Biology
  <https://doi.org/10.1016/0022-5193(69)90015-0>`_. Boolean-network context;
  this package implements fixed motifs, not a random topology ensemble.
* `dit documentation <https://dit.readthedocs.io/en/latest/>`_: inspiration for
  the organization into concepts, model catalog, examples and API reference.

No third-party generator code or research dataset is bundled. The package's
small mechanisms are original implementations. Citations identify context,
not reproduction or endorsement. Sphinx and its Read the Docs theme are
optional documentation dependencies and retain their own licenses.
